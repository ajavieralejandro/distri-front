# Analytics demo

Indicadores derivados de fixtures/MSW (no números hardcodeados independientes).

- Admin: `/admin/analytics` — ventas, pedidos, ticket, stock bajo, deuda, pagos, entregas.
- Comercio: `/commerce/dashboard` — solo datos propios.

Filtros: 7 días, 30 días, mes actual.

Visualización: tarjetas, barras CSS, tablas. Sin librería de charts.

Sustitución futura: endpoints analíticos OpenAPI de Distrisoft API.
